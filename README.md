# CodeAlpha FAQ Chatbot - Task 2

An intelligent FAQ Chatbot that answers CodeAlpha related queries using NLP.

**Features:**
- TF-IDF Vectorization for question matching
- Cosine Similarity for best answer retrieval
- Handles internship FAQs automatically

**Tech Stack:** Python, Scikit-learn, NLP

**How to Run:**
pip install -r requirements.txt
python chatbot.py
